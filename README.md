# Portafolio de Landing Pages

Colección de **9 landing pages** construidas como archivos HTML independientes. Cada una explora un estilo visual distinto (corporativo, editorial, brutalista, glassmorfismo, etc.) aplicado a una marca ficticia.

No requieren build ni dependencias: basta con abrir cualquier archivo de la carpeta [`html/`](html/) en el navegador.

## Estructura

```
Portafolio/
├── html/   # Una landing por archivo .html
└── imgs/   # 3 capturas de pantalla por proyecto
```
